وب‌سایت همدل - راهنمای انتشار رایگان

۱) فایل ZIP را استخراج کنید.
۲) در مخزن GitHub خود گزینه Add file و سپس Upload files را بزنید.
۳) همه فایل‌ها و پوشه‌های داخل این پوشه را بارگذاری کنید؛ خود فایل ZIP را بارگذاری نکنید.
۴) در پایین صفحه Commit changes را انتخاب کنید.
۵) وارد Settings مخزن شوید.
۶) از منوی کناری Pages را باز کنید.
۷) در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
۸) Branch را روی main و پوشه را روی /(root) بگذارید و Save را بزنید.
۹) پس از چند دقیقه نشانی سایت در همان صفحه Pages نمایش داده می‌شود.

نکته: فایل index.html باید مستقیماً در ریشه مخزن باشد.
این نسخه ایستا است و به پایگاه داده یا هاست PHP نیاز ندارد.
